# Controls reference

## Terminal view

| Control | Action |
| --- | --- |
| Start | Open the keyboard |
| Menu, short press | Send the Menu button event to the terminal |
| Menu, hold | Open actions and help |
| Y, short press | Arm Ctrl for the next key |
| Y, hold | Send Ctrl+C once |
| A | Restart an ended local shell |

The stick does not scroll the terminal. Reset and power controls are not read by the application.

## On-screen keyboard

| Control | Action |
| --- | --- |
| D-pad | Move between keys |
| A | Type the selected key |
| B | Close the keyboard |
| X | Toggle lowercase and uppercase |
| Y | Toggle letters and numbers |
| Start | Send Enter |
| Select | Toggle Alt |
| L1 | Cycle symbols, navigation and letters |
| R1 | Send Backspace |
| L2 | Select the previous completion |
| R2 | Select the next completion |
| Stick press | Accept the selected completion |

## Action menu

| Action | Result |
| --- | --- |
| Help | Open terminal and keyboard help |
| Restart terminal | Close the current shell and start a new one after confirmation |
| Clear terminal | Clear the visible terminal state after confirmation |
| Exit | Close Pocket Terminal after confirmation |

## Terminal bell

A terminal bell produces a brief silent border flash. Repeated bells are rate-limited.
